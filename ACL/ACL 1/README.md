##Project Description## This laboratory exercise focuses on the implementation of fundamental network security using Access Control Lists (ACLs) on Cisco infrastructure. This scenario simulates the restriction of access rights between different network segments—such as HR, IT, and Server departments—to ensure data integrity and privacy within a local network environment.

#Instructional Objectives: -Network Security: Comprehend the methods for filtering data packets based on source IP addresses, destinations, and specific protocol ports. -Traffic Management: Regulate data flow so that server resources are only accessible by authorized hosts.
-CLI Implementation: Practice the precise syntax for Standard and Extended ACLs using the Cisco IOS Command Line Interface. -Network Analysis: Perform verification to ensure applied security rules align with organizational policies.

#Learning Outcomes: Upon completion of this lab, the practitioner is expected to: -Distinguish clearly between the functions and applications of Standard and Extended ACLs. -Diagnose connectivity issues resulting from improper ACL rule placement, including the "Implicit Deny" concept. -Harden local server access against potential internal and external threats. -Execute Verification using commands like show access-lists and testing via pings or web browsers within Cisco Packet Tracer.
